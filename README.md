# Portfolio

Personal portfolio of Ayush Shrestha, a full stack and DevOps engineer in Kathmandu.

A static site with no build step: `index.html` and `css/style.css`. Open `index.html` in a browser, or turn on GitHub Pages for this repository (Settings, Pages, deploy from the `master` branch) to host it.

Fonts (Schibsted Grotesk and Source Serif 4) load from Google Fonts, with system fonts as the fallback.
