Systems I own

Three systems at Mentor Friends, where I am the technical lead and owner of each.

Source is private. These are company projects, so the code is not public. Everything below is what I built and what I measured.

FreeSchema on Kubernetes In production

About ten services (.NET Core, Node.js, React) run on a bare-metal two-node k3s cluster, with no managed cloud underneath.

Problem
About ten services had to run reliably on two physical servers.
Approach
k3s with autoscaling (HPA) and PodDisruptionBudgets on the API services. nginx as the gateway. MySQL with semi-sync replication and ProxySQL for read/write splitting.
Operations
Failover tested against a real outage. MySQL upgraded from 8.0 to 8.4 on a 27 GB database. Prometheus, Grafana, Loki and Alertmanager with Slack alerts. A published npm CLI sets up, seeds, backs up and restores a deployment.
Delivery
An in-house CI/CD system, a CI secret-scanning workflow, and k6 load tests.

GraphSync In progress

A graph traversal engine for FreeSchema, written in C#/.NET.

16.1Mrows, concepts table
20.6Mrows, connections table
4-wayself-joins today
7 to 8 sper query today
Problem
Analytics queries are four-way self-joins over those two tables. Each takes seven to eight seconds and appears hundreds of times in the slow log.
Approach
A memory-mapped compressed sparse row (CSR) graph, kept in step with MySQL over MQTT and replicated independently on each node.
Decision
Edges cross user boundaries, so sharding per user was ruled out.
Status
In progress. I have not yet measured the result, so I quote no speedup.

Video transcoding and HLS service 39 tests passing

A separate service so video work never blocks the main app. It turns uploaded MP4 files into adaptive HLS streams from 144p to 1080p.

LayerChoice
APINode.js, TypeScript, Fastify. OpenAPI docs generated from Zod schemas
ProcessingFFmpeg, with a BullMQ queue
StateRedis only, with TTL expiry. No database
StorageCloudflare R2
SecurityTwo-layer auth (API key plus bearer token), rate limiting on every endpoint

A structured code review found 17 issues: 1 critical (a concurrency crash), 1 high, 4 medium and 10 low. I fixed all of them. I also fixed Safari playback by converting 10-bit HEVC to 8-bit H.264.

Incident: 504 cache stampede

A short write-up of a production fix.

Symptom
A stateful .NET service returned 504 errors.
Cause
A cache stampede in a stateful service that relies on an in-memory cache.
Fix
Cookie-based session affinity, routed through an internal ingress-nginx hop.
Constraint
Done without changing any existing routes.
