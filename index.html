// systems

Systems I own at Mentor Friends

I am the technical lead and owner of these three. They are company projects, so the source is private.

FreeSchema on Kubernetes

In production

About ten services (.NET Core, Node.js, React) on a bare-metal two-node k3s cluster, with autoscaling and PodDisruptionBudgets on the API services. MySQL runs with semi-sync replication and ProxySQL, and failover was tested against a real outage.

Monitoring is Prometheus, Grafana, Loki and Alertmanager with Slack alerts. A published npm CLI sets up, seeds, backs up and restores a deployment.

One fix I am proud of: a 504 cache stampede in a stateful .NET service, solved with cookie-based session affinity and no change to existing routes.

GraphSync in progress

C#/.NET

A graph traversal engine for FreeSchema. Analytics queries were four-way self-joins over tables of 16 and 20 million rows, taking seven to eight seconds each. GraphSync keeps an mmap-backed compressed sparse row graph in step with MySQL over MQTT, replicated independently on each node.

Video transcoding and HLS service

Node.js, TypeScript

A REST API that turns uploaded MP4 files into adaptive HLS streams from 144p to 1080p, so video work never blocks the main app. It uses Fastify, FFmpeg, a BullMQ queue, Redis and Cloudflare R2, with two-layer auth, rate limiting and OpenAPI docs generated from Zod schemas.

39 passing tests. A code review found and fixed 17 issues, including one critical concurrency crash.
