FreeSchema on Kubernetes

In production

.NET Core, Node.js, React, k3s, MySQL, Prometheus

One fix. A 504 cache stampede in a stateful .NET service, solved with cookie-based session affinity and no change to existing routes.

  • Prometheus, Grafana, Loki and Alertmanager, with Slack alerts
  • In-house CI/CD, secret scanning and k6 load tests

GraphSync

Completed

C#/.NET, MQTT, MySQL

A graph traversal engine for FreeSchema, built to replace four-way self-join analytics queries that took 7 to 8 seconds each over tables of 16.1M and 20.6M rows.

  • Memory-mapped compressed sparse row (CSR) graph
  • Kept in step with MySQL over MQTT
  • Replicated independently on each node
  • No per-user sharding, because edges cross users

Video transcoding and HLS service

In production

Node.js, TypeScript, Fastify, FFmpeg

A separate service so video work never blocks the main app. It turns uploaded MP4 files into adaptive HTTP Live Streaming (HLS) streams from 144p to 1080p.

  • Two-layer auth: API key plus bearer token
  • Rate limiting on every endpoint
  • OpenAPI docs generated from Zod schemas
  • BullMQ queue, job state kept only in Redis
  • Storage on Cloudflare R2
