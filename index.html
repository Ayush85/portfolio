01 · In production

FreeSchema on Kubernetes

.NET Core, Node.js, React, k3s, MySQL, Prometheus

Problem
About ten services had to run reliably on two physical servers, with no managed cloud to lean on.
What I did
Built a bare-metal two-node k3s cluster with autoscaling and PodDisruptionBudgets on the API services. Set up MySQL with semi-sync replication and ProxySQL, and tested failover against a real outage. Added Prometheus, Grafana, Loki and Alertmanager with Slack alerts, plus a published npm CLI that sets up, seeds, backs up and restores a deployment.
One fix
A 504 cache stampede in a stateful .NET service, solved with cookie-based session affinity and no change to existing routes.

02 · In progress

GraphSync

C#/.NET, MQTT, MySQL

Problem
Analytics queries were four-way self-joins over two large tables. Each took seven to eight seconds and appeared hundreds of times in the slow log.
What I am building
A graph traversal engine that keeps a memory-mapped compressed sparse row graph in step with MySQL over MQTT, replicated independently on each node. Edges cross user boundaries, so per-user sharding was ruled out.

03

Video transcoding and HLS service

Node.js, TypeScript, Fastify, FFmpeg, BullMQ, Redis, Cloudflare R2

Problem
Video processing could not be allowed to block the main app.
What I did
Built a separate REST API that turns uploaded MP4 files into adaptive HLS streams from 144p to 1080p, with two-layer auth, rate limiting on every endpoint, and OpenAPI docs generated from Zod schemas. A structured code review found 17 issues, including one critical concurrency crash, and I fixed all of them. I also fixed Safari playback by converting 10-bit HEVC to 8-bit H.264.
